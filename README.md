# PVCC Coding Club Presents Blackjack

This is the bare minimum starter point for our blackjack game.

## Getting started

To start, you only need two things:

- [VS Code](https://code.visualstudio.com) or your favorite IDE
- [Node.js](https://nodejs.org/en/download)

Start by setting up your environment:

1. Follow the instructions to install VS Code
2. Follow the instructions to install Node.js
   1. Get Node.js `v26.13.1`
   2. Using `nvm` (macOS/Linux) or `fnm` (Windows)
   3. With `npm`

Once both are installed, open this project and open a terminal:

1. Start the website in development mode: `npm run dev` 
2. Open the website in your browser: `http://localhost:5173/`
3. Start editing code and watch it update in real time!

## Developing

Once your environment is set up and working, you're ready to start building:

1. Learn about React using the links in the [Canvas post](https://learn.vccs.edu/courses/860199/pages/blackjack-design-notes)
2. Read my own guide, using examples from this very project, in [GUIDE.md](./GUIDE.md)

## Publishing (mainly for Mr. Ferero)

Simply run the build command, and the website's files will be placed in `dist`:

1. Build the website: `npm run build`
2. Copy the files in `dist` to any web server
3. The final website is live!
